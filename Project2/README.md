MORSE CODE TRANSMITTER

This project converts text input from the Serial Monitor into Morse code signals. 
Each alphabet is mapped to its corresponding Morse pattern using dots and dashes. The Arduino reads the input character and uses an LED and buzzer to represent dots as short signals and dashes as long signals.

The components used are:

1. Arduino UNO
2. LED
3. Buzzer 
4. 220Ω resistor

With the buzzer, we can identify the message sent by the beep sound.
Long beep - Dash
Short beep - Dot

With the LED , we can visually identify the code.
Long blink - Dash
Short blink - Dot

The circuit is simple. So the connections should be taken care off. The resistor should not be forgotten.
